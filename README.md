# pn-tools

ProductNow-maintained Claude Code plugins, distributed via a self-hosted marketplace.

## Install

```
/plugin marketplace add ProductNowAI/pn-tools
/plugin install seed-rtfm@productnow
```

## Plugins

- **seed-rtfm** — seeds a first-pass RTFM documentation corpus into ProductNow for the repository you run it in. Run `/seed-rtfm` after installing. Requires a ProductNow MCP key (Settings → MCP in the ProductNow app), which the plugin prompts for on install.
